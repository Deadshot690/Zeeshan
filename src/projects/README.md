# Projects Media Library

This directory holds the raw production video assets categorized by discipline:
- `Color Grading/`
- `Motion Graphics/`
- `Video Editing/`
- `Visual Effects/`

> **Note on Web Delivery:**
> Next.js serves static assets exclusively from the `/public` root. High-efficiency streaming copies with faststart moov atoms and mobile-responsive posters are published in `/public/assets/videos/` and `/public/assets/showreel/`.
